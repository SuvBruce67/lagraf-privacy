# lagraf-privacy
# Политика конфиденциальности Lagraf

Lagraf хранит ваши системы на вашем компьютере и телефоне. Единственное подключение к интернету — вход в ваш Google Диск, чтобы синхронизировать системы между вашими устройствами.

Приложение получает доступ только к папке «Lagraf», которую само создаёт на вашем Google Диске. Другие файлы Диска приложение не видит и не читает.

Мы не собираем, не передаём и не продаём никакие данные. Приложение не отправляет аналитику и не показывает рекламу.

Чтобы отключить синхронизацию и удалить доступ, нажмите «Выйти» в настройках приложения или отзовите доступ в настройках аккаунта Google.
